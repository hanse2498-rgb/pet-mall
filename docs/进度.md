> 更新时间：2026-10-12（隔日恢复运行用）

## 一、当前运行方式

```bash

cd D:\java\mall\frontend && pnpm dev
```

- 后台：http://localhost:5173/admin　（账号 `admin` / `Admin@123`，启动自动创建）

## 二、已完成功能

### 商城前台
- **商品域**：分类树、品牌、列表（关键词/分类/品牌/宠物/价格筛选+排序+分页）、详情（轮播/SKU/临期）、临期专区（7折）、宠物猫狗×食品用品首页推荐（每个模块2张卡并排）
- **账户**：验证码登录 / 密码登录 / 注册 / 忘记密码（验证码5min有效+60s冷却+每日10条；密码BCrypt；连错5次锁15分钟）、收货地址CRUD、用户禁用后不可登录
- **购物车**：加购/数量/勾选/删除/角标；满200包邮否则运费10
- **订单**：下单（地址快照/乐观锁扣库存/食品批次校验+快照/幂等）、列表/详情/取消（回补库存）/确认收货/**超时自动取消（30min定时任务）**
- **模拟支付**：成功/失败演示，成功后清购物车
- **商品评价**：详情页评分汇总+评价列表（昵称脱敏/星级/图文/加载更多），已完成订单可写评价（每单商品一次）
- **个人中心**：顶栏用户名下拉进入 `/profile`；**内嵌我的订单**（状态Tab+操作）、我的评价、我的收藏（详情页收藏按钮）、浏览足迹
- **宠物社区**：导航「宠物社区」(`/community`)——发布宠物日常（**本地图片上传**）、最新/热门信息流、点赞、一级评论、删自己的；详情页 `/community/:id`
- **图片上传**：`/api/upload/image` 本地磁盘存储（`backend/upload/`），静态访问 `/files/**`；通用组件 `ImageUploader.vue`（选图即上传/预览/删除，≤9张/≤5MB）
- 列表排版：全部商品 **每行5个 × 每页6行(30)** 翻页；分类新增 **服饰/出行**（共8类）

### 后台管理
- 管理员认证（admin/Admin@123，角色隔离，普通token返回403）
- **商品管理**：增删改/上下架/SKU/**批次（自动算剩余占比+临期7折）**/**按分类模块查看**
- 品牌/分类 CRUD
- **订单管理**：全局列表/详情/发货
- **用户管理**：搜索/禁用/启用

## 四、数据说明

- `backend/src/main/resources/db/`：
  - `init.sql` 建库建表（用户/商品/订单/购物车/售后/发票/**收藏/足迹/社区** 等，共 26+ 张表）
  - `seed_demo.sql` 演示商品+SKU+批次（33个商品，含宠物类型 pet_type、服饰/出行分类）
  - `seed_reviews.sql` 演示评价
  - 增量补丁：`patch_categories.sql`（服饰/出行）、`patch_extra.sql`（补商品到30+）、`patch_community.sql`（社区表+演示动态）
- 批量重置演示数据：依次执行 init.sql + seed*.sql + patch*.sql（会重建 mall 库）。
- 验证码/限流/幂等为**内存实现**，重启后清空；生产需换 Redis。
- **图片上传**存本地 `backend/upload/`（`application.yml` 的 `upload.dir`），静态访问 `/files/**`。
- **问答助手**默认本地知识库；接外部大模型设置环境变量后重启后端：`AI_PROVIDER=openai`、`AI_BASE_URL=...`、`AI_API_KEY=...`、`AI_MODEL=...`。无论本地/外部都只答宠物相关话题（非宠物硬性拦截）。
