# 宠物商城 · 技术栈（确定版）

> 更新时间：2026-10-10　版本：v1.0

## 总体
纯**网页端**、**前后端分离**。

## 前端

| 项 | 选择 |
| --- | --- |
| 框架 | Vue 3 + Vite |
| 语言 | TypeScript |
| 路由 / 状态 | Vue Router + Pinia |
| UI | Element Plus（后台）+ 移动端适配 |
| HTTP | Axios（统一封装） |
| 规范 | ESLint + Prettier，pnpm |

## 后端

| 项 | 选择 |
| --- | --- |
| 语言 | Java 17 |
| 框架 | Spring Boot 3.x |
| 构建 | Maven |
| ORM | **MyBatis-Plus** |
| 权限 | **Sa-Token** |
| 校验 | spring-boot-starter-validation |
| 生成 | Lombok + MapStruct |

辅料：统一响应体 + 全局异常、SpringDoc(Swagger)、雪花 ID、订单幂等、库存乐观锁。

## 数据 / 中间件

| 项 | 选择 |
| --- | --- |
| 关系库 | MySQL 8.0 |
| 缓存 | **Redis 7**（会话、购物车、库存预扣、热数据） |
| 连接池 | HikariCP |
| 搜索 | 暂用 MySQL 模糊查询（100 SKU） |
| 消息队列 | 暂不上 |
| 任务调度 | Spring @Scheduled（订阅提醒、临期检查、订单超时） |
| 文件存储 | MinIO（自建） |

## 对接 / 支付

| 项 | 选择 |
| --- | --- |
| 支付 | **模拟支付模块**：`PaymentService` 接口 + Mock 实现，预留微信支付位 |
| 物流 | 第三方物流接口预留 |
| 第三方登录 | 预留 |

## 部署 / 工程化

Docker + docker-compose（nginx + backend + mysql + redis + minio）；Nginx 托管前端并反向代理 `/api`；JUnit5 + Mockito + Postman。

## 工程结构

单仓库、前后端分工程、后端单体模块化：

```
mall/
├─ docs/
├─ frontend/        # Vue3 + Vite
└─ backend/         # Spring Boot 单体
    └─ src/main/java/com/mall/
        ├─ module/  (product / order / member / subscribe / aftersale / invoice / admin)
        ├─ common/
        └─ config/
```
