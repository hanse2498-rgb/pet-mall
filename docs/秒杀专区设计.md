# 秒杀专区 · 设计方案（V1）

> 状态：已确认　2026-10-13　导航：首页/全部商品/临期专区/**🔥秒杀专区**/宠物社区

## 已确认决策

| 项 | 决策 |
| --- | --- |
| 场次 | **多场次定时开场**（后台建场次，设起止时间） |
| 限购 | 每人每个秒杀商品**限购 1 件** |
| 库存 | **独立秒杀库存**（不占普通 SKU 库存） |
| 入口 | 导航独立专区页 `/seckill` + **首页秒杀入口横幅** |

## 数据模型（3 张新表）

- `tb_seckill_activity`：id、name、start_time、end_time、status(0未开始/1进行中/2已结束/3关闭)、create_time
- `tb_seckill_item`：id、activity_id、sku_id、seckill_price、seckill_stock、seckill_sold、per_user_limit(=1)、status、sort
- `tb_seckill_record`：id、user_id、item_id、quantity、create_time，唯一(user_id+item_id)

## 功能

### 用户端
- `/seckill` 专区页：场次切换 + 顶部倒计时（未开始/进行中/结束）+ 商品网格（秒杀价、原价划线、已抢进度、剩余件数）
- 商品详情复用 + 秒杀价 + 「立即秒杀」
- 秒杀下单 → 校验（场次进行中/SKU上架/限购1件/秒杀库存）→ 原子扣秒杀库存 → 复用订单+模拟支付+发货流程
- 首页加秒杀入口横幅（一期静态入口，可有倒计时）

### 后端
- 场次状态（按当前时间）
- `GET /api/seckill/{activityId}`：场次信息+商品列表+服务器时间
- `GET /api/seckill/current`：当前可买/即将开始场次（首页/专区用）
- `POST /api/seckill/order`：秒杀下单（校验规则见上，防超卖 `UPDATE ... WHERE seckill_stock>=qty`）
- 后台：场次 CRUD、场次内秒杀商品维护（秒杀价/库存/上下架）

### 工程注意
- 倒计时基于服务器时间（接口返回 serverTime）
- 防超卖：DB 原子扣减；量产升级 Redis 预扣
- 限购：tb_seckill_record 唯一(user+item)，下单即落库校验
