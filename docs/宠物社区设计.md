# 宠物社区 · 设计（V1）

> 状态：已确认方案　2026-10-12　对应需求「社区/UGC · P1 后置项」

## 目标

导航栏新增「宠物社区」独立板块：注册用户晒宠物日常（文字 + 图片），支持互动（点赞/评论）。

## 已确认决策

| 项 | 决策 |
| --- | --- |
| 图片 | **URL 占位**（先不做 MinIO 上传，后续统一接对象存储） |
| 评论 | **一级评论**（不做楼中楼） |
| 审核 | **暂不做**（后续再加敏感词/举报/后台审核） |
| 入口 | **独立页面**（导航「宠物社区」→ `/community`） |

## 页面

1. `/community` 社区首页：信息流（最新/热门 Tab）+ 发布框；未登录只读
2. `/community/:id` 动态详情：图片/文字 + 评论列表 + 评论输入
3. 发布：首页发布框/按钮（文字 ≤500 + 图片 URL ≤9）
4. 导航「宠物社区」放在「临期专区」旁

## 功能清单（V1）

- 发布动态（登录）、删除自己的动态
- 信息流分页：最新 / 热门（点赞+评论加权）
- 点赞/取消点赞（同一用户一贴一次）
- 一级评论：发评论（登录）、评论列表、删除自己的评论
- 浏览计数
- 动态详情页
- 未登录：可浏览，发布/点赞/评论需登录（引导）

## 数据模型

- `tb_post`（id, user_id, pet_id 可空, content, images JSON, like_count, comment_count, view_count, status, create_time, update_time, deleted）
- `tb_post_like`（id, user_id, post_id，唯一 user+post）
- `tb_post_comment`（id, post_id, user_id, content, create_time）

## 不做（V2 待定）

楼中楼、互动通知、举报/审核、标签广场、宠物档案联动、图片真上传（MinIO）。

## 开发顺序

1. 建表 + 后端接口（发布/列表/详情/删除、点赞、评论）
2. 「宠物社区」导航 + 首页信息流 + 发布 + 详情/评论
3. 我的社区（我发布的/我赞过的）接个人中心（可选 V2）
