# 宠物商城 · 数据库表设计

> 基于 MyBatis-Plus + MySQL 8。命名 `tb_` 前缀，主键用 `BIGINT`（雪花ID）。
> 公共字段：`create_time`、`update_time`、`deleted`(逻辑删除)。
> 覆盖：用户/宠物/商品/购物车/订单/支付/物流/订阅/发票/售后/评价/通知/后台。

## 用户域
`tb_user`：id, phone(唯一), password_hash, nickname, avatar, status(0禁用1正常), last_login_time, create_time, update_time, deleted
`tb_user_address`：id, user_id, receiver_name, phone, province, city, district, detail, is_default, create_time, update_time, deleted

## 宠物域
`tb_pet`：id, user_id, nickname, species(猫/狗/其他), breed, birth_date, weight_kg, is_neutered, allergy, remark, create_time, update_time, deleted

## 商品域
`tb_brand`：id, name, logo, description, status, sort, create_time, update_time, deleted
`tb_category`：id, parent_id, name, level, sort, status, create_time, update_time, deleted
`tb_product`：id, brand_id, category_id, name, subtitle, cover_img, images(JSON), detail_html, sale_type(0普通1食品), is_near_expiry, shelf_status(0下架1上架), sales, create_time, update_time, deleted
`tb_sku`：id, product_id, spec_name, price, original_price(划线价), stock, sales, status, version(乐观锁), create_time, update_time, deleted
`tb_sku_batch`：id, sku_id, batch_no, produce_date, expiry_days(保质期天数), remain_ratio(剩余占比,可算), is_near_expiry, create_time, update_time, deleted
`tb_product_tag`（可选）：id, product_id, tag

> 说明：临期折扣用 price=原价×0.7 落地到 SKU，或存 `discount_price`；建议 SKU 增加 `is_discount` 字段 + `discount_price`。

## 购物车域
`tb_cart`：id, user_id, sku_id, quantity, selected, create_time, update_time
> 若用 Redis 缓存购物车，Redis 为主、此表为持久化底账。

## 订单域
`tb_order`：id, order_no(唯一), user_id, receiver(快照 JSON), status(0待支付1待发货2待收货3已完成4已取消5售后中), goods_amount, discount_amount, freight, pay_amount, pay_status, remark, pay_time, ship_time, finish_time, cancel_time, create_time, update_time, deleted
`tb_order_item`：id, order_id, sku_id, product_name, sku_img, spec, price, quantity, subtotal, batch_id, produce_date, expiry_date, create_time, update_time

## 支付域
`tb_payment`：id, order_id, pay_no(唯一), channel(0=mock 模拟,预留1微信), amount, status(0待支付1成功2失败), pay_time, create_time, update_time

## 物流域
`tb_shipping`：id, order_id, logistics_company, tracking_no, status(0已发货1运输中2已签收), ship_time, receive_time, create_time, update_time

## 订阅域
`tb_subscription`：id, user_id, sku_id, cycle_days, status(0active1paused2cancelled), next_deliver_date, last_notify_time, create_time, update_time, deleted
`tb_subscription_notify`：id, subscription_id, user_id, notify_time, create_time

## 发票域
`tb_invoice`：id, user_id, order_id, type(0个人1企业), title, tax_no, email, amount, status(0已申请1已开票2失败), issue_time, create_time, update_time

## 售后域
`tb_after_sale`：id, order_id, order_item_id, user_id, type(0退1换2质量售后), reason, amount, status(0申请中1处理中2已完成3已拒绝), handle_note, operator_id, apply_time, update_time

## 评价域
`tb_review`：id, user_id, order_id, product_id, sku_id, rating(1-5), content, images(JSON), status, create_time, update_time

## 通知域
`tb_notification`：id, user_id, type, title, content, is_read, create_time

## 后台域
`tb_admin_user`：id, username(唯一), password_hash, nickname, status, role_id, last_login_time, create_time, update_time
`tb_role`：id, name, code, permission(JSON), create_time, update_time

---
## 关键索引建议
- `tb_order(order_no)` 唯一；`(user_id, status)`
- `tb_sku(product_id)`、商品列表按 `(category_id, status)`
- `tb_subscription(user_id, status)`、`(next_deliver_date)` 供到期扫描
- `tb_user(phone)` 唯一；`tb_user_address(user_id)`
- `tb_sku_batch(sku_id)`、`(is_near_expiry)`
- `tb_notification(user_id, is_read)`

## 待定参数映射（实现时落库或在配置）
- 包邮阈值 ¥200、固定运费 ¥10 → 可做成后台配置项
- 保质期发货下限 2/3、临期阈值 1/3、临期折扣 0.7 → 后台临期参数表/配置
- 订阅周期 15/30/60 → 可配置
