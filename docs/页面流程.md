# 宠物商城 · 核心页面流程

> 前台（用户端）+ 后台（运营端），文字描述页面与流转。

## 一、页面总览

**前台**
首页 → 分类 / 品牌 / 搜索 / 临期专区 → 商品列表 → 商品详情 → 购物车 → 结算 → 支付(模拟) → 订单列表/详情 → 我的(账户 / 地址 / 宠物 / 订阅 / 发票 / 售后 / 评价) → 站内通知

**后台**
登录 → 工作台 → 商品管理 / 库存(批次、临期) / 订单管理 / 售后 / 用户 / 品牌 / 优惠 / 发票 / 临期参数设置

## 二、购物主流程

```
首页 / 搜索 / 分类 / 临期专区
        │
        ▼
   商品列表（筛选/排序）
        │
        ▼
   商品详情（规格SKU、库存、保质期、临期标识）
        │                 │（加入订阅）
        ▼                 ▼
   加入购物车          订阅设置(周期)
        │                 │
        ▼                 ▼
  ┌─购物车(勾选/改量) ─ 订阅管理(暂停/恢复/取消)
  │
  ▼
  结算页
  │  地址 / 运费(满200包邮 / 固定10) / 优惠券(预留) / 备注
  ▼
  提交订单（幂等，锁库存）
  ▼
  模拟支付  → 成功(待发货) / 失败·超时(自动取消)
  ▼
  运营发货(填物流公司+单号)
  ▼
  物流跟踪 → 确认收货(已完成)
  ▼
  评价 / 申请发票 / (异常)申请售后
```

## 三、订阅提醒流程

```
商品详情点击「订阅」
  → 选周期(15/30/60)  →  临期校验(临期不可订阅)
  → 生成订阅(active)
  → 定时任务每日扫描到期(subscription 到期日)
  → 站内通知「您订阅的XX该补货啦」+ 跳转商品
  → 用户手动下单
  → 订阅未被取消：进入下一周期；用户可暂停/改期/取消
```

## 四、售后流程（用品 / 食品）

```
订单详情 → 申请售后（选择订单项、类型）
  ├─ 用品：7天无理由退换（校验：未过7天、包装完好、不影响二次销售）
  └─ 食品：质量问题/临期/过期 → 退/补
        │
        ▼
  生成售后单(status=申请中)
        ▼
  运营处理（同意→退款/补发 / 拒绝→附理由）
        ▼
  已完成 / 已拒绝
```

## 五、保质期与临期页面体现

- **商品管理/库存（后台）**：维护批次（生产日期、保质期、剩余/占比），自动计算并标识「临期」。
- **商品详情（前台）**：食品显示生产日期/保质期/剩余；临期显示「临期 · 7折」标识。
- **临期折扣专区（前台）**：只展示临期食品，7 折，不可订阅、不参与满200包邮计算（按实际售价）。

## 六、发票流程

```
已完成订单 → 发票中心 → 申请电子发票
  → 选择抬头(个人/企业，企业需税号) + 邮箱
  → 状态：已申请 → 已开票(附下载) / 开票失败
```

## 七、后台订单发货

```
订单列表 → 详情 → 「发货」
  → 填物流公司 + 运单号（食品发货校验剩余保质期≥2/3）
  → 状态 待发货→待收货，推送站内通知
```

## 八、状态机汇总

**订单**：待支付 → 待发货 → 待收货 → 已完成
　　│　　　　　　└→(超时/手动)已取消
　　└→(售后中) 售后中 → 已完成/已拒绝

**售后**：申请中 → 处理中 → 已完成 / 已拒绝
**订阅**：active → paused → cancelled；next 到期触发提醒
**发票**：未申请 → 已申请 → 已开票 / 开票失败
