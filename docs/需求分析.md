# 宠物商城 · 需求分析（拟稿）

> 文档版本：v0.6（定稿）　更新时间：2026-10-10

## 一、项目定位

面向**独居养宠人群**的宠物用品/食品商城。做**自营单商城**的
`浏览 → 下单 → 支付(模拟) → 履约 → 售后` 完整闭环，以**订阅复购提醒**与
**食品新鲜度（保质期/临期）管理**为差异化能力。

## 二、范围界定

**本期做（In Scope）**
- 宠物用品、食品的完整交易闭环
- 订阅到期提醒下单（不自动下单、不自动扣款）
- 食品保质期管理 + 临期商品折扣专区
- 电子发票、模拟支付

**本期不做（Out of Scope）**
- 活体宠物交易
- 服务预约（洗澡/寄养/上门喂养/问诊）
- 社区 / UGC 内容
- 智能硬件联动
- 多商家平台化、真实微信支付

## 三、已锁定决策

| 项 | 决策 |
| --- | --- |
| 经营范围 | 仅宠物用品/食品 |
| 经营模式 | 自营单商城（无多商家） |
| 目标人群 | 独居养宠人群（先聚焦） |
| 平台形态 | H5 / 网页，移动优先 |
| 支付 | 模拟支付入口（暂不接真实微信支付） |
| 配送 | 自建发货 + 第三方物流 |
| 运费 | 订单商品金额满 **¥200 包邮**，否则**固定运费 ¥10** |
| 订阅 | 到期**站内提醒**下单，不自动生成订单、不扣款 |
| 商品规模 | 约 100 SKU，多品牌 |
| 发票 | 电子发票 |
| 退换货 | 用品支持 7 天无理由；食品不支持（质量/临期/过期走质量售后） |
| 保质期发货下限 | 剩余保质期 ≥ 总保质期的 **2/3** 方可发货 |
| 临期定义 | 剩余保质期 ≤ 总保质期的 **1/3** 标记「临期」 |
| 临期折扣 | 固定 **7 折**，进入临期折扣专区，不可订阅 |

## 四、用户角色

| 角色 | 说明 |
| --- | --- |
| 游客 | 浏览、搜索商品，不能下单 |
| 注册用户（会员） | 下单、订阅、管理宠物档案/订单/发票/评价 |
| 运营 / 管理员 | 商品、订单、库存、用户、品牌、优惠、发票、临期管理 |

## 五、核心业务闭环

1. **一次性购买**：浏览/搜索 → 详情 → 加购 → 结算（地址/运费/优惠）→ 模拟支付 → 履约 → 收货 → 评价 → 售后
2. **订阅复购提醒**：选择商品设周期 → 到期站内提醒 → 用户手动下单
3. **履约**：支付成功 → 发货（填物流单号）→ 轨迹 → 确认收货 → 退换/质量售后

## 六、功能需求清单

编号规则 `FR-模块-序号`，`P0`=首发必做，`P1`=二期。

### 1. 账户与会员
- FR-ACC-01 (P0) 注册登录（手机号验证码、第三方登录）
- FR-ACC-02 (P0) 收货地址管理（多地址、默认地址）
- FR-ACC-03 (P1) 会员等级 / 积分

### 2. 宠物档案
- FR-PET-01 (P0) 宠物信息：昵称、种类、品种、生日/年龄、体重、绝育、过敏史
- FR-PET-02 (P0) 支持多只宠物
- FR-PET-03 (P1) 档案驱动的个性化推荐 / 换粮/补货提醒

### 3. 商品与分类
- FR-CAT-01 (P0) 多级分类：主粮、零食、玩具、清洁护理、医疗保健、智能设备等
- FR-CAT-02 (P0) 商品列表：排序（销量/价格/上新）、分页
- FR-CAT-03 (P0) 商品详情：图文、规格 SKU、价格、库存、参数、适用宠物、保质期
- FR-CAT-04 (P0) 商品标签：新品、热销、独家、CC 猫/狗、适用月龄
- FR-CAT-05 (P0) 品牌属性 + 按品牌筛选（P1：品牌专区）

### 4. 搜索与推荐
- FR-SCH-01 (P0) 关键词搜索、搜索历史
- FR-SCH-02 (P0) 常用筛选：品类、品牌、宠物类型、价格区间、适用阶段
- FR-SCH-03 (P1) 个性化推荐 / 猜你喜欢

### 5. 购物车与结算
- FR-CART-01 (P0) 加购、改数量、删除、选中结算
- FR-CART-02 (P0) 结算页：地址、运费（满200包邮/固定10）、优惠券、备注
- FR-CART-03 (P0) 库存校验、过期/下架/临期提示
- FR-CART-04 (P1) 优惠券

### 6. 支付与订单
- FR-ORD-01 (P0) 创建订单、状态机（待支付/待发货/待收货/已完成/已取消/售后中）
- FR-ORD-02 (P0) 模拟支付入口（含支付失败/超时即可模拟）
- FR-ORD-03 (P0) 订单列表/详情、物流跟踪、确认收货
- FR-ORD-04 (P1) 取消订单、修改地址（限未发货）

### 7. 订阅复购提醒
- FR-SUB-01 (P0) 选择商品并设置订阅周期（15/30/60 天等）
- FR-SUB-02 (P0) 订阅管理：修改周期、暂停、恢复、取消、删除
- FR-SUB-03 (P0) 到期**站内提醒**，引导手动下单
- FR-SUB-04 (P1) 智能补货建议
- FR-SUB-05 (P0) **临期商品不可订阅**

### 8. 食品保质期 / 临期管理
- FR-FRESH-01 (P0) 食品 SKU 记录生产日期、保质期、批次、剩余保质期
- FR-FRESH-02 (P0) 发货校验：剩余保质期 ≥ 总保质期 2/3
- FR-FRESH-03 (P0) 剩余保质期 ≤ 1/3 标记「临期」，7 折，进入临期折扣专区
- FR-FRESH-04 (P0) 临期商品不可订阅、撤下正常售卖可提示
- FR-FRESH-05 (P0) 详情页展示保质期与临期提示

### 9. 售后与评价
- FR-AFS-01 (P0) 用品 7 天无理由退换（不影响二次销售、包装完好）
- FR-AFS-02 (P0) 食品质量/临期/过期售后（退款/补发）
- FR-AFS-03 (P0) 售后进度跟踪
- FR-AFS-04 (P0) 收货后评价（文字 + 图片）

### 10. 发票
- FR-INV-01 (P0) 申请电子发票：抬头类型（个人/企业）、税号、邮箱、状态
- FR-INV-02 (P0) 开票状态跟踪

### 11. 通知
- FR-NOT-01 (P0) 订单状态通知（支付/发货/收货）
- FR-NOT-02 (P0) 订阅到期站内提醒
- FR-NOT-03 (P1) 营销消息

### 12. 运营后台
- FR-ADM-01 (P0) 商品与 SKU、库存（含保质期/批次）
- FR-ADM-02 (P0) 订单管理与发货、售后处理
- FR-ADM-03 (P0) 用户管理
- FR-ADM-04 (P0) 品牌、优惠、临期参数管理
- FR-ADM-05 (P0) 电子发票管理
- FR-ADM-06 (P1) 数据看板（GMV、复购率、订阅数）

## 七、非功能需求（业务层）

- 移动端 H5 优先，桌面端基础可用
- 商品列表/详情/结算响应快，具备大促韧性
- 信任：正品保障、真实评价、售后时效
- 合规：个人信息保护、宠物食品/用品相关规范、电子发票
- 后台可独立运营商品与活动

## 八、MVP（第一版）范围

**必做**：账户/地址、宠物档案、商品分类/详情/品牌、搜索筛选、购物车结算、
下单 + 模拟支付、订单与物流、订阅提醒、保质期/临期 + 折扣专区、用品 7 天无理由
售后 + 食品质量售后、评价、电子发票、站内通知、运营后台（商品/订单/用户/发票/临期）。
**二期**：会员积分、个性化推荐、营销活动、数据看板、品牌专区。

## 九、关键业务规则

1. 运费：商品金额满 ¥200 包邮，否则固定 ¥10。
2. 退换货：用品 7 天无理由；食品按质量/临期/过期售后。
3. 发货：食品剩余保质期 ≥ 2/3 总保质期。
4. 临期：剩余 ≤ 1/3 → 7 折、进专区、不可订阅。
5. 订阅：仅站内提醒，不自动下单/扣款。
6. 支付：模拟，暂不接真实微信支付。
